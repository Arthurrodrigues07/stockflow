
# StockFlow

Sistema de gestão de estoque e vendas desenvolvido com HTML, CSS e JavaScript.

## Sobre o projeto

O StockFlow é uma aplicação web responsiva para simular o gerenciamento comercial de pequenos negócios.

O sistema permite cadastrar produtos, controlar quantidades em estoque, registrar vendas e acompanhar indicadores financeiros.

## Funcionalidades

- Dashboard com indicadores financeiros
- Cadastro, edição e exclusão de produtos
- Controle de estoque e movimentações
- Alertas de estoque baixo
- Registro de vendas com múltiplos produtos
- Atualização automática do estoque
- Histórico de vendas
- Relatórios de faturamento
- Cálculo de lucro bruto estimado
- Gráficos de desempenho
- Exportação e importação de backup JSON
- Armazenamento local com localStorage
- Layout responsivo

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor.

## Observações

Este projeto foi desenvolvido para fins educacionais e de portfólio.

Os dados são armazenados localmente no navegador. O sistema não possui autenticação, banco de dados remoto ou integração fiscal.

Não é recomendado utilizá-lo como sistema comercial de produção sem adaptações adicionais.
