Privacidade e armazenamento

O StockFlow utiliza armazenamento local do navegador. Não é necessário criar uma conta e os dados não são sincronizados com outros dispositivos. Limpar os dados do navegador pode apagar os registros. Faça backups regularmente.

Este projeto é uma demonstração educacional de gestão comercial. Não substitui sistemas fiscais, contábeis ou de controle empresarial em produção.
